LLM Translation 使用说明
====================================

一、这个软件是做什么的
把英文 PDF / EPUB / Word 书籍翻译成中文 Word（.docx），尽量保留章节、图表、脚注和目录。
翻译通过网络调用你选择的翻译服务完成，软件本身不包含免费的 API Key。

二、第一次使用（3 步）
1. 双击桌面上的 “LLM Translation” 图标。
2. 在“服务商”里选择 DeepSeek（推荐，价格低），把申请到的 API Key 粘贴到输入框。
   申请地址：https://platform.deepseek.com/api_keys
3. 点“选择文件”选中要翻译的 PDF，再点“开始翻译”。

三、翻译过程中
- 进度条和日志会显示当前进行到哪一步；大书可能需要几十分钟，取决于页数和网络速度。
- 翻译时请不要关闭窗口。需要停止时点“中止”，已经翻译的部分会留在本机缓存里。
- 完成后会提示输出位置，并生成一个文件名带 _zh_print 的 .docx 文件。

四、英文原词（书名和专名的英文括注）
界面上的“英文原词”有三个档位，默认是“较多（推荐）”：
- 较多：书名、人名、机构、地名、条约、关键术语第一次出现时，都写成“中文（English）”。
  书名和专名在每一章重新括注一次；术语表里的词会自动补上英文，重复翻译时不会叠加。
- 适度：全书只在第一次出现时括注，后面只写中文。
- 关闭：完全不保留英文括注，书名也只写中文。

觉得英文太少就选“较多”；觉得中英混排碍眼就选“适度”或“关闭”。
想让某本书的书名或术语固定译法，可在程序目录的 config\glossary.tsv 里加一行
“English<TAB>中文”（用 Tab 分隔），翻译时会优先采用。

五、输出文件在哪里
- 默认输出到原文件旁边的“文件名_out”文件夹，可以在界面上改成其他位置。
- 文件夹里通常有：
  - xxx_zh_print.docx：最终中文译稿
  - proof_report.md / proof_report.csv：校对报告，提示未翻译、数字、术语等问题
  - preview.pdf：预览版（软件内置转换引擎，不需要另装 Office 或 LibreOffice）
- 用 Word/WPS 打开 docx 后，按 Ctrl+A、再按 F9，可更新目录页码。

六、常见问题
1) 提示“没有可用文字层”
   这是扫描版 PDF。请先用带 OCR 的 PDF 工具（如 Acrobat、ABBYY）做成“可搜索 PDF”，
   或改用电子版 PDF。
2) 预览 PDF 没有生成
   软件已内置 LibreOffice Kit，正常情况下会自动生成。若仍然失败，请查看日志中
   “DOCX 转 PDF 失败”的提示，并把安装目录下的日志发给我们；docx 译稿不受影响。
3) 杀毒软件提示有风险
   本软件没有购买代码签名证书，个别杀毒软件会把 Python 程序和内置的文档转换引擎
   误报为风险。请确认安装包来自你信任的来源，并选择“允许/信任”。软件只访问你填写的
   翻译服务地址，不包含广告、挖矿或后门程序。转换引擎固定在
   C:\ProgramData\LLMTranslationKit，卸载时会一并删除。
4) API Key 安全吗
   API Key 只保存在本次运行的内存里，不写入磁盘，也不会上传到作者服务器。
   服务商、模型、输出目录等偏好设置保存在：%LOCALAPPDATA%\LLMTranslation\settings.json。
   公用电脑请在卸载时选择“全部删除”。
5) 同一个文件重复翻译会重复收费吗
   不会。软件会在本机缓存译文，相同文件第二次翻译不会再次调用接口，也不再消耗 token。
   注意：从 1.0.0 升级到 1.1.0 时翻译规则有更新，1.0.0 留下的译文缓存不再复用。
   1.1.0 及以后版本共用同一套翻译规则，升级到 1.2.0 后已翻译的内容仍走缓存，不重复收费。

七、卸载
开始菜单 → 设置 → 应用 → 已安装的应用 → LLM Translation → 卸载。
卸载时会出现两个选项：
- 保留配置和缓存（推荐）：下次安装后可以直接继续使用，不用重新填 Key。
- 全部删除：偏好设置和翻译缓存一并清除。

八、系统要求
Windows 10 / Windows 11（64 位），约 450 MB 磁盘空间。
不需要安装 Python、Java、.NET 运行库、Office 或 LibreOffice；安装包已内置
Node 和 LibreOffice Kit，DOCX 转换、正文排版和目录页码开箱即用。
