# LLM Translation 1.1.0

本版重点：译稿里的英文原词可以分级保留，默认比 1.0.0 保留更多书名、人名和专名原文。

## 下载

- **Windows 10 / 11（64 位）安装包**：`LLMTranslation_Setup_1.1.0.exe`
- 免安装源码运行：克隆仓库后按 README 安装依赖

安装包按当前用户安装，不需要管理员权限、Python 或任何运行库。安装后从桌面或开始菜单启动，
填入自己的翻译 API Key 即可使用。

## 新增：英文原词分级

界面新增“英文原词”下拉框，也可在 `config/config.json` 的 `source_gloss.mode` 设置：

| 档位 | 效果 |
| --- | --- |
| **较多（推荐，默认）** | 书名、人名、机构、地名、条约、关键术语首次出现时写成“中文（English）”；书名和专名每章重新括注一次 |
| 适度 | 全书只在第一次出现时括注，后面只写中文 |
| 关闭 | 不保留英文括注，书名也只写中文 |

配套的确定性处理：

- 术语表命中的词会在译文中自动补 `中文（English）`，同一作用域每词只补一次，不重复叠加；
- 同一书名的英文括注只保留一处（较多档按章、适度档按全书），其余自动去重；
- 人名括注优先使用原文全名，例如“沃伦（Mark Warren）”而不是只括姓氏；
- 关闭档会清掉已有的书名括注，并让人名只保留中文；
- 想固定某本书的书名或术语，可在 `glossary.tsv` 添加 `English<TAB>中文`，翻译与括注都以它为准。

## 其他

- 英文原词档位会随其他偏好一起保存在 `%LOCALAPPDATA%\LLMTranslation\settings.json`；
- 卸载时选择“保留配置和缓存”，重装后档位仍然生效；
- “重新排版”会按当前档位重新应用括注与书名去重。

## 升级提示

翻译提示词和缓存版本已更新（`v5`），**1.0.0 生成的译文缓存不会复用**。
同一本书重新翻译会重新调用接口并产生新的 token 费用；只重排已有 `book.json` 不受影响。

## 系统要求

- Windows 10 / Windows 11（64 位）
- 翻译需要网络和对应服务商的 API Key
- 可选：Microsoft Word、WPS 或 LibreOffice，用于生成 PDF 预览和目录页码回填

## 已知限制

- 书名括注由模型按规则生成；写法不统一时可用 `glossary.tsv` 固定
- 安装包未购买代码签名证书，SmartScreen 可能提示“未知发布者”
- 扫描版 PDF 需先做 OCR 得到可搜索 PDF
- 目录识别依赖原书目录页或 PDF 书签
- 表格按原版面渲染为图片嵌入，不在 Word 中重建单元格
